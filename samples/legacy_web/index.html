GAS / HTTP POST 連携
HTTP 200だけで成功にしません。リダイレクト先のJSON応答が ok:true、同じrecord_id の場合に送信済みとします。送信失敗は検査を止めません。テストは type:test を送り、例文のGASでは履歴に追加しません。
送信JSONの例文
{"type":"camera_result","record_id":"JOB-0001-020000000001","carton":"0001","camera_slot":1,"mac":"020000000001","sn":"EXAMPLE-SN-001","old_ip":"192.168.0.150","new_ip":"192.168.0.220","result":"OK","appearance":"OK","network":"OK","rtsp":"OK","ir_cut":"OK","settings":"OK","tool_version":"2.0.0"}
GASからの返信例
{"ok":true,"record_id":"JOB-0001-020000000001","duplicate":false}
GAS受信コード例を保存。GASへ貼り付け、スクリプトプロパティ SPREADSHEET_ID に保存先IDを設定し、Webアプリとしてデプロイしてください。
